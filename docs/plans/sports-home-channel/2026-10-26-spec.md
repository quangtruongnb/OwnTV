# Sports preview channel on the Android TV home screen — spec

Date: 2026-10-26

## Goal

Publish a **"Sports"** preview channel on the Android TV home screen listing the profile's followed
matches that are **live now or kick off within the next 7 days**. Selecting a card opens the app's
match page (Find channels / Watch live from there).

## Constraints

- No change to core (`tv.own.owntv:core`, upstream). Everything lives in the app module so upstream
  pulls stay conflict-free.
- Gated by the existing Settings switch `androidTvHomeEnabled` (same as core's "Recent live" channel
  and Watch Next).
- No-op where TvProvider is missing (phones, Fire TV).

## Components (`app/.../features/sports/tvhome/`)

| Component | Role |
|---|---|
| `SportsChannelPlanner` | For each followed league/team (`SportsConfig`), `SportsSource.scoreboard(league, date)` for today … today+6. Keep live + not-started matches, drop finished, live first then kick-off, cap 30. |
| `SportsChannelPublisher` | Creates the "Sports" `PreviewChannel` once (id kept in DataStore), `requestChannelBrowsable` on first creation, diffs programs (insert / update / delete) keyed by `internalProviderId = match.key`. Deletes the channel when disabled. |
| `SportsChannelWorker` | Periodic WorkManager job, **every 15 min**, network required. Plus a one-off run on app start and on profile switch. Cancelled when `androidTvHomeEnabled` is off. |
| `SportsChannelDeepLink` | `owntv://sports/match?key=…&feed=…&id=…&start=…` build + parse. |

## Card content

- Type `TYPE_EVENT`; title "Home vs Away" (or `match.title`); description: league + score or kick-off time.
- Poster: home team logo, else league logo.
- Live flag set while `match.isLive`; start/end times set from `startMs`.

## Deep link flow

`MainActivity` parses the sports link before `LauncherDeepLink`. The shell resolves the match:
board → planner's in-memory days → the league's scoreboard around the kick-off date.
It then opens the existing match page. The channel's own link (`owntv://open/sports`) opens the hub.

## Errors

- A league fetch failure keeps that league's previously published cards.
- Provider/security exceptions are caught and logged; never crash the worker.

## Tests

Unit tests: planner (7-day window, filtering, ordering, cap), program diff, deep link round-trip.
